# GroupDNA

GroupDNA is a simple Python-based project that analyzes exported WhatsApp chat data and generates useful statistics about conversations and participant activity.

## Concepts Used

- Python
- NumPy
- File Handling
- Dictionaries
- Lists
- Loops
- Conditional Statements
- String Manipulation
- Date and Time Handling (`datetime`)
- Basic Data Analysis
- Sorting
- Message Parsing
- Text Processing
- Statistical Calculations

## Features

- Read WhatsApp chat export
- Count total messages and participants
- Detect media and deleted messages
- Find most active participant
- Find most active day and hour
- Analyze messaging patterns
- Generate simple chat statistics

## Requirements

- Python 3.x
- NumPy

## Input

- Exported WhatsApp chat (`.txt`)

## Output

The program displays chat statistics such as:
- Total messages
- Participant activity
- Most active day
- Peak messaging hour
- Media and deleted message count
